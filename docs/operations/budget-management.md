# 予算フォーム変更時の確認

予算の動作は `specs/13-budget-management.md` を正本とする。

- 当月と翌月へ異なる予算を保存し、月移動リンクで往復して入力欄がそれぞれの月の金額になることを確認する。
- 同じ月の保存後は成功通知と新しい金額を確認する。再保存と停止が競合せずに完了することを確認する。
- 他の管理者との同時編集で競合した場合は、再読み込みして最新の予算を確認してから編集する。新しい改定を読み込んだ場合、未保存入力はその改定の金額へ更新される。
- 停止の確認中に別の月へ移動した場合は、遷移先で改めて停止確認が必要になる。
- 自動確認は `tests/e2e/budgets.spec.ts`、入力状態の回帰確認は `src/modules/budgets/presentation/budget-editor.test.tsx` を実行する。
